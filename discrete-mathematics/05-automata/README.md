# Topic 5 — Automata Theory

This lab implements a deterministic finite automaton (DFA) from first principles using C. The implementation models states, transitions, accepting states, and string recognition to connect formal-language theory with lexical-analysis concepts.

## Concepts Practised

- Alphabets
- Strings
- Formal languages
- DFA states
- Transition functions
- Accepting states
- Deterministic computation
- Regular languages
- Lexical-analysis foundations

## Lab Objective

Build a DFA that recognises binary strings containing an even number of `1` symbols.

## Files

- `dfa.h` — DFA data structures and interfaces
- `dfa.c` — DFA implementation
- `main.c` — demonstration
- `test_dfa.c` — automated tests
