# Topic 2 — Set Theory Foundations

This laboratory implements fundamental concepts from set theory using C.

The purpose is to translate mathematical definitions into executable algorithms.

## Concepts

Implemented concepts include:

- sets
- membership
- subsets
- union
- intersection
- difference
- Cartesian products
- power-set cardinality

## Mathematical Connection

Sets provide the mathematical foundation for relations.

```
Set
 ↓
Cartesian Product
 ↓
Relation
 ↓
Relational Algebra
 ↓
Database Systems
```

#### Operations

Union:
```
A ∪ B
```

Intersection:
```
A ∩ B
```

Difference:
```
A − B
```

Cartesian product:
```
A × B
```

Power set cardinality:
```
|P(A)| = 2^|A|
```


### Learning Objective

The objective is to understand set theory as a computational structure rather than memorising definitions.

The implementation connects the mathematical definitions studied in Topic 2 with the relational structures used by databases, algorithms, and later graph theory.
