# Topic 4 — Combinatorics

This lab implements fundamental counting techniques including factorials, permutations, combinations, and the binomial coefficient. The purpose is to translate mathematical counting definitions into executable algorithms and observe the relationship between recursive definitions and computational complexity.

## Concepts Practised

- Factorials
- Permutations
- Combinations
- Binomial coefficients
- Pascal's identity
- Recursive definitions
- Counting algorithms

## Lab Objective

Implement core combinatorial functions and verify them through automated tests.

## Files

- `combinatorics.h` — function interfaces
- `combinatorics.c` — implementations
- `main.c` — demonstration
- `test_combinatorics.c` — automated tests
