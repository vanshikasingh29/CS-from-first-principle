# Topic 3 — Graph Theory

This lab implements fundamental graph-theory concepts using C, including vertices, edges, adjacency relationships, traversal, and shortest-path reasoning. The implementation connects mathematical graph definitions with practical representations and algorithms used in computer science.

## Concepts Practised

- Graphs
- Directed and undirected graphs
- Vertices and edges
- Adjacency
- Breadth-first search
- Depth-first search
- Shortest paths
- Graph representation

## Lab Objective

Build a small graph library from first principles and use it to explore graph traversal and connectivity.

## Files

- `graph.h` — graph data structures and interfaces
- `graph.c` — graph implementation
- `main.c` — practical demonstration
- `test_graph.c` — automated tests
