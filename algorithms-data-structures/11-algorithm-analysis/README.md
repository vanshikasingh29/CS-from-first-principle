# Topic 11 — Algorithm Analysis & Complexity

Practical laboratory work for algorithmic complexity and performance analysis.

## Concepts

- Big-O notation
- Linear complexity: O(n)
- Logarithmic complexity: O(log n)
- Quadratic complexity: O(n²)
- Linear search
- Binary search
- Recursive algorithms
- Empirical runtime analysis
- Worst-case reasoning

## Objective

Implement and experimentally compare algorithms with different
asymptotic complexities.

The purpose is to connect formal complexity analysis with
observable program behaviour.

## Algorithms

| Algorithm | Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Nested Loop | O(n²) |
| Recursive Sum | O(n) |
