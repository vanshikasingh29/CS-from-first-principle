# Topic 12 — Dynamic Programming

Practical implementation of dynamic programming techniques from first principles.

## Concepts

- Overlapping subproblems
- Optimal substructure
- Memoisation
- Tabulation
- State definition
- Recurrence relations
- Bottom-up optimisation
- Space complexity

## Implementations

- Fibonacci using memoisation
- Fibonacci using tabulation
- 0/1 Knapsack
- Minimum-cost path
- Longest Common Subsequence

## Objective

Translate mathematical recurrence relations into efficient algorithms while analysing their time and space complexity.
