# Topic 13 — Greedy Algorithms

Practical implementation of greedy algorithm techniques from first principles.

## Concepts

- Greedy choice property
- Optimal substructure
- Local vs global optimisation
- Activity selection
- Fractional knapsack
- Minimum spanning trees
- Kruskal's algorithm
- Complexity analysis

## Objective

Understand when a locally optimal choice can produce a globally optimal solution, and distinguish greedy problems from problems requiring dynamic programming.
