# Topic 14 — Advanced Graph Algorithms

Practical implementation of shortest-path algorithms from first principles.

## Algorithms

- Dijkstra's algorithm
- Bellman-Ford algorithm
- Floyd-Warshall algorithm
- Shortest-path reconstruction
- Negative edge handling
- All-pairs shortest paths

## Objective

Understand how different shortest-path algorithms operate, when each is valid, and how their time and space complexity differ.

## Complexity

| Algorithm | Time | Negative Edges |
|---|---:|---|
| Dijkstra | O(V²) | No |
| Bellman-Ford | O(VE) | Yes |
| Floyd-Warshall | O(V³) | Yes |

This laboratory focuses on implementation and algorithmic reasoning rather than a production graph library.
