# Topic 7 — Bit-Level Arithmetic

## Purpose

This lab explores how integers are represented and manipulated at the bit level.

The exercises implement common low-level operations using C bitwise operators.

## Concepts

- Binary representation
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bitwise NOT
- Left shift
- Right shift
- Setting a bit
- Clearing a bit
- Toggling a bit
- Testing a bit
- Counting set bits

## Why It Matters

Bit-level operations are fundamental to:

- CPU architecture
- operating systems
- memory systems
- embedded systems
- cryptography
- networking
- performance engineering

The purpose of this lab is to connect high-level C operations with the binary representation manipulated by hardware.
