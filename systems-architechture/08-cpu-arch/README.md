# Topic 8 — CPU Architecture

## Purpose

This lab models the fundamental stages of CPU execution using a small software CPU simulator.

The simulator demonstrates:

- registers
- program counter
- instruction register
- fetch
- decode
- execute
- arithmetic operations
- memory access
- control flow
- CPU state transitions

## CPU Execution Cycle

The model follows:

Fetch
↓
Decode
↓
Execute
↓
Update CPU state

## Why It Matters

Modern processors are vastly more complex, but the fundamental idea remains:

instructions are fetched, decoded, and executed while processor state changes.

This lab connects high-level programming with the architecture underneath compiled code.
