# Topic 21 — Vector Spaces

This laboratory implements fundamental vector-space operations from first principles in C.

## Concepts

- Vectors
- Scalar multiplication
- Vector addition
- Dot products
- Vector norms
- Linear combinations
- Linear independence

## Purpose

The implementation connects the mathematical definition of vector spaces with executable algorithms.

These concepts form the mathematical foundation for:

- linear algebra
- machine learning
- dimensionality reduction
- neural networks
- optimisation
