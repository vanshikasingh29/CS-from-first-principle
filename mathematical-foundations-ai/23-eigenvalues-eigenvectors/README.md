# Topic 23 — Eigenvalues & Eigenvectors

This lab explores eigenvalues and eigenvectors from first principles.

The implementation demonstrates how matrices can have special directions that remain unchanged in direction when transformed, with only their magnitude changing.

## Mathematical Relationship

For a square matrix A:

A v = λ v

where:

- A = matrix
- v = eigenvector
- λ = eigenvalue

The vector changes in magnitude but remains in the same direction.

## Practical Connection

Eigenvalues and eigenvectors are fundamental to:

- PCA
- spectral clustering
- PageRank
- dimensionality reduction
- numerical methods
- differential equations
- computer graphics
