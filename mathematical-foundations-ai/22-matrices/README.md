# Topic 22 — Matrices

## Layer 2 — Practical Laboratory

This laboratory implements fundamental matrix operations from scratch in C.

The purpose is to connect the mathematical theory of matrices with their computational representation.

## Concepts Implemented

- Matrix creation
- Matrix destruction
- Element access
- Matrix addition
- Scalar multiplication
- Matrix multiplication
- Matrix transpose
- Identity matrices
- Matrix-vector multiplication

## Computer Science Connections

Matrices are fundamental to:

- machine learning
- computer graphics
- computer vision
- robotics
- scientific computing
- numerical algorithms

A matrix can also represent a linear transformation:

A × x = y
