# Topic 24 — Multivariable Calculus

This lab explores the mathematical foundations of multivariable calculus used in machine learning.

## Concepts

- Partial derivatives
- Gradients
- Jacobians
- Directional derivatives
- Numerical differentiation
- Multivariable functions

## Mathematical Foundation

For a function:

f(x, y)

the gradient is:

∇f = [∂f/∂x, ∂f/∂y]

The gradient describes the direction of greatest increase of the function.

## Practical Connection

Multivariable calculus is fundamental to:

- machine learning
- optimisation
- neural networks
- gradient descent
- backpropagation
- scientific computing

## Implementation

The lab implements numerical partial derivatives and gradients and compares them with analytical derivatives.
