# Mission Statement

> **To develop a deep, first-principles understanding of computer science by connecting mathematical theory, software engineering, and computer systems into one complete mental model.**

Modern software engineering is not only about writing code.

The strongest engineers understand:

- why programs behave the way they do,
- how software interacts with hardware,
- how algorithms are designed and analysed,
- how operating systems manage computation,
- and how mathematical foundations power modern technologies such as artificial intelligence.

This repository documents my journey towards building that level of understanding.

---

# Project Overview

**CS From First Principles** is a self-directed computer science engineering programme designed to bridge the gap between:

```
Writing Programs
        ↓
Understanding Systems
        ↓
Understanding Theory
        ↓
Building Advanced Software
```

The goal is not to memorise technologies.

The goal is to understand the principles that remain constant across technologies.

This repository represents a structured progression through:

- Systems Programming
- Computer Architecture
- Discrete Mathematics
- Algorithms
- Operating Systems
- Networking
- Linear Algebra
- Machine Learning Foundations

# Learning Philosophy

## First Principles Engineering

Instead of learning frameworks first, this project follows the same philosophy used by strong computer science programmes:

```
Mathematics
     ↓
Theory
     ↓
Implementation
     ↓
Engineering Application
```

Every concept is studied through three layers:


## Layer 1 — Theory

Understanding the mathematical and computer science foundations.

Includes:

- formal definitions,
- proofs,
- architectural concepts,
- algorithms,
- computational reasoning.


---

## Layer 2 — Implementation

Turning theory into engineering.

Each topic includes:

- production-quality code,
- documented experiments,
- reusable implementations,
- GitHub portfolio projects.


---

## Layer 3 — Research & Reading

Connecting concepts to academic material.

Using:

- university lecture notes,
- textbooks,
- research papers,
- industry documentation.

# Engineering Principles

This repository follows these principles:

## Understand Before Implementing

Code is the result of understanding, not the replacement for it.


## Build From Fundamentals

Higher-level abstractions become easier when the underlying mechanisms are understood.


## Document Everything

Good engineering requires communication as much as technical ability.


## Learn Through Construction

The best way to understand a system is to build a simplified version.


## Think Like An Engineer

Focus on:

- trade-offs,
- scalability,
- correctness,
- efficiency,
- maintainability.
